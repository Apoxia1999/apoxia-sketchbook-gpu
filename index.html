Atajos e interacción

Los atajos de herramientas se usan fuera de los editores de texto. Ctrl equivale a ⌘ en macOS.

Moverse y ver
Botón central + arrastrar
Mover el canvas.
Espacio + arrastrar
Mover el canvas sin cambiar de herramienta.
Rueda / pellizco
Zoom alrededor del cursor. En modo Trackpad, deslizar mueve el canvas; Ctrl + deslizar hace zoom.
Z + arrastrar
Zoom horizontal con el botón izquierdo. También Alt + arrastrar con el botón derecho.
H
Encuadrar todo el contenido.
Espacio
Abrir el original bajo el cursor o el lector de una nota. Esc cierra el lector.
1–5
Volver a una vista guardada.
Espacio + 1–5
Guardar la vista actual en ese número.
Dos dedos
En pantalla táctil: desplazar y pellizcar para hacer zoom.
Herramientas y selección
Shift + dibujar
Crear una línea recta desde el inicio del trazo hasta el cursor.
R
Rectángulo redondeado: arrastrar para crear; Shift mantiene la proporción. Esc cancela. Después, arrastrar el borde para mover.
E
Dibujar; ajustar el grosor en la barra lateral.
D
Goma; ajustar su radio en la barra lateral.
W
Magic Laser: trazar sobre los elementos para seleccionarlos, incluidos dibujos. Arrastrar la selección para moverla.
Alt al dibujar
Activar Magic Laser temporalmente. Después de mover la selección, un clic fuera vuelve a dibujar. En imágenes, Alt permite recortar.
Arrastrar en vacío
En modo mover, seleccionar imágenes, vídeos, notas y Scribe con un rectángulo. Los dibujos se seleccionan con Magic Laser.
Esc
Quitar la selección; cancelar un rectángulo, una conexión o un recorte en curso.
Objetos, copiar y borrar
Arrastrar
Mover un objeto o una selección. Arrastrar bordes o esquinas para cambiar el tamaño.
Ctrl + arrastrar
Duplicar fotos, textos, formas o dibujos seleccionados y mover las copias.
Ctrl+C
Copiar el objeto bajo el cursor o la selección. Notas, Scribe e imágenes también se copian al portapapeles del sistema.
Ctrl+V
Pegar objetos centrados en el cursor. Si el portapapeles contiene una imagen externa, importarla como al añadir un archivo.
X
Borrar el elemento de encima bajo el cursor, incluidas las flechas. Si es un acceso a un archivo, primero quitar el vínculo; otra X borra el elemento.
Supr / Retroceso
Borrar la selección; también el texto Scribe seleccionado.
L / Q
Bloquear o desbloquear el objeto bajo el cursor; si no hay uno, usar la selección.
Ctrl+Z
Deshacer.
Ctrl+Y / Ctrl+Shift+Z
Rehacer.
Recortar imágenes
Alt + borde
Mantener Alt y arrastrar un borde o esquina para recortar. Soltar el ratón aplica; Esc cancela.
Mantener Alt
Ver el original atenuado y ampliar el marco para recuperar zonas. Rebasar el original quita todo el recorte.
Original intacto
El recorte se puede deshacer. Ctrl+C copia la zona visible; descargar el original conserva la imagen completa.
Texto, notas y temas
S + clic
Activar Scribe y hacer clic para escribir sobre el canvas.
T
Crear una nota en el cursor.
Doble clic
Editar una nota o un texto Scribe. En una nota, otro doble clic sale de edición.
Esc / Ctrl+Enter
Terminar y guardar la edición de Scribe.
Shift + arrastrar
Mover una nota sin alineación magnética.
C
Sobre una nota: cambiar su color. En el canvas sin selección: cambiar de tema.
V
Mostrar u ocultar el fondo de la nota bajo el cursor.
Ctrl+F
Buscar texto en notas y Scribe. Enter avanza; Shift+Enter retrocede; Esc cierra.
Fijar en pantalla
F
Fijar el elemento bajo el cursor a la pantalla. Si hay elementos fijados, F los libera todos.
Alt+Z + arrastrar
Zoom con el botón izquierdo manteniendo fijo el tamaño del objeto o selección bajo el cursor.
Alt + Espacio + arrastrar
Arrastrar el canvas manteniendo fijo el objeto o selección bajo el cursor.
Archivos, conexiones y Vaults
Añadir / soltar
Importar imágenes, vídeos y SVG de contornos. También puedes arrastrar una imagen o pin de Pinterest al canvas.
Clip con selección
Vincular un archivo a la selección. En modo mover, un clic en el elemento vinculado abre el archivo.
Puntos de conexión
Arrastrar desde un punto lateral de un objeto a otro para conectarlos. La goma también borra conexiones.
Controles al pasar
Al pasar sobre un objeto aparecen sus acciones: copiar, bloquear, borrar y acceder al original, según el tipo.
Vault
Crear una zona cifrada con el botón del candado. Abrir con contraseña; mover por la cabecera o bordes y redimensionar desde la esquina.
Vault pequeña
Doble clic para acercarla y encuadrarla.
ZIP y DATA
En Opciones: exportar o importar un canvas ZIP y copiar a DATA los archivos que están vinculados.
